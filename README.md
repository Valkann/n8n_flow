# n8n flows

A collection of n8n flows.

| Flow | Description |
|---|---|
| [Save Mastodon Bookmarks to Raindrop](./mastodon-bookmarks-to-raindrop/README.md) | Automatically archives Mastodon bookmarks into a Raindrop.io collection for future reference and tagging. |
| [Save Mastodon Bookmarks to Wallabag](./mastodon-bookmarks-to-wallabag/README.md) | Saves new Mastodon bookmarks to Wallabag, remembers its position in a Data Table and skips URLs that already exist. |
| [Random French TTRPG from itch.io](./itchio-jdr-aleatoire/README.md) | Picks a random French, AI-free tabletop RPG from the itch.io RSS feed, ready to be posted on social media. |

## Usage

Open a flow's folder, copy the content of `workflow.json` and paste it on the n8n canvas (`Ctrl+V`).
